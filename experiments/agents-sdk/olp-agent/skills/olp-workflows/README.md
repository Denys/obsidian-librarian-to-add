# OLP Workflow Notes

Use this local note as the reusable policy summary for the OLP agent:

- OLP source repo and target library folders are separate.
- Scan and classify before planning an ingest wave.
- Start with one small text source or one small PDF chapter.
- Preview before draft writes.
- Validate, review quality, index, and search-smoke after each wave.
- Promotion and unpromotion require explicit approval.
